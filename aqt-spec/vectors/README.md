# Conformance test vectors (Evidence Records 0.1)

Generated by `scripts/gen_vectors.py`; deterministic (fixed IDs and times, RFC 8032 test keys), so regeneration is byte-identical. Licence: Apache-2.0.

| Folder | Content |
|---|---|
| `canonical/` | Raw JSON text → canonical bytes and hash, or a required parse error (floats, duplicate keys, lone surrogates, …) |
| `valid/` | Valid records with expected record hash, content hash, canonical form and signature results |
| `invalid/` | Records every implementation must reject |
| `chained/` | Intact chains, unsigned and signed |
| `tampered/` | Edited, inserted, deleted, reordered, wrongly started and rewritten chains, with the first broken `seq`; two vectors show what a chain alone cannot detect |
| `signed/` | Checkpoints (valid, truncated log, rewritten log, tampered, unpinned key) and detached signed statements |

`keys.json` holds the published RFC 8032 §7.1 TEST 1 and TEST 2 keys. **TEST ONLY**: anyone can sign with them.

The format of each file and how to run them is described in [`../docs/implementers.md`](../docs/implementers.md). The reference library agrees with every vector (`aqt-evidence vectors`).
