> Agent Quality Toolkit supports quality-management practices; it is not a validated system and does not by itself make any process compliant with GMP, GDP, 21 CFR Part 11 or EU Annex 11.

**How to read it.** *Supported by* names AQT features that produce evidence or controls relevant to the clause; it never means the clause is met. *Evidence* lists the record types those features write. *You still must* lists duties that stay with the user (procedures, training, validation, administration). An empty *Supported by* means AQT does not help with this clause.
